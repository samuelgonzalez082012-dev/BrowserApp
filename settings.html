05

Keyboard shortcuts

Customize shortcut keys. These use Ctrl (or Command on macOS), with Shift where specified.

Avoid changing these to keys already used by common browser shortcuts. Ctrl+L, Ctrl+T, Ctrl+W and Ctrl+R remain standard browser shortcuts.

06

Browser behavior

Fine-tune how pages load and how inactive tabs are handled.

Sleeping tabs reload when opened. Unsaved form state can be lost.

System Downloads folder (change from Downloads panel).

07

Backup and restore

Move your personal browser setup or keep a safety copy.

Backups include workspaces, tabs saved for restoration, bookmarks, history, notes, collections, sessions and settings. AI API credentials are excluded.
